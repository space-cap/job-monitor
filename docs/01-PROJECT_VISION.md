# 01. Project Vision

## 1. 목적

`job-monitor`는 채용공고를 반복해서 검색해야 하는 수고를 줄이고, 사용자가 원하는 조건의 공고만 빠르게 확인할 수 있도록 만드는 채용정보 모니터링 시스템이다.

현재는 Work24를 유일한 수집 대상으로 삼는다. 향후 다른 소스를 추가할 수 있도록 Core와 Collector의 역할을 분리한다.

## 2. 핵심 사용자 시나리오

1. Work24의 채용 목록을 주기적으로 수집한다.
2. 공고를 MariaDB에 저장하고 중복을 제거한다.
3. Thymeleaf 화면에서 수집 결과와 상태를 확인한다.
4. 사용자가 `경비`, `시설관리`, `미화` 등의 키워드와 조건을 등록한다.
5. 신규 공고가 Rule에 일치하면 Slack으로 전달한다.
6. 이미 알림한 공고는 중복 발송하지 않는다.

## 3. 핵심 원칙

- MVP는 Work24 하나에 집중한다.
- Collector는 수집과 저장에 집중한다.
- Spring Boot Core는 조회, Rule, 알림, 관리 화면을 담당한다.
- DB를 시스템의 중심 데이터 저장소로 사용한다.
- 수집 실패와 알림 실패를 분리하여 재처리할 수 있어야 한다.
- 비밀정보는 코드와 문서에 저장하지 않는다.

## 4. 장기 방향

현재는 1인 사용을 전제로 개발하지만, 데이터 모델과 Rule 구조는 향후 여러 사용자가 각자의 조건을 등록할 수 있도록 확장 가능하게 설계한다.
