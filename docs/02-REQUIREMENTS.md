# 02. Requirements

## 1. MVP 기능 요구사항

### Collector

- Work24 채용 목록 페이지를 수집한다.
- 페이지당 50건 기준으로 목록을 수집한다.
- 목록에서 상세 공고 URL과 식별자를 확보한다.
- 필요한 경우 상세 페이지를 추가 수집한다.
- HTML 파싱 실패를 로그로 남긴다.
- 수집 결과를 MariaDB에 저장한다.
- 동일 공고의 중복 저장을 방지한다.

### Core

- 저장된 공고를 Thymeleaf로 조회한다.
- 제목, 회사, 근무지, 급여, 고용형태, 마감일, 원문 URL 등을 검색한다.
- 신규/변경/중복/오류 통계를 제공한다.
- Rule을 등록하고 활성화/비활성화한다.
- Rule에 일치하는 신규 공고를 조회한다.
- Slack 알림 발송 결과를 기록한다.

### Notification

- Slack Webhook 또는 Slack API를 사용한다.
- 공고 제목, 회사, 근무지, 급여, 마감일, 원문 링크를 포함한다.
- 동일 Rule과 동일 공고의 중복 알림을 방지한다.
- 발송 실패를 기록하고 재처리 가능하게 한다.

## 2. 비기능 요구사항

- Collector와 Core 장애가 서로 직접 전파되지 않도록 한다.
- 모든 수집 작업은 실행 이력을 남긴다.
- DB 접속정보와 Slack 인증정보는 환경변수로 관리한다.
- HTTP 요청에는 적절한 User-Agent, timeout, retry 정책을 적용한다.
- 과도한 요청을 피하고 Work24 서비스에 불필요한 부하를 주지 않는다.

## 3. MVP 제외

- 사람인/잡코리아 등 추가 수집원
- 회원가입/소셜 로그인
- 모바일 앱
- 복잡한 AI 추천
- 유료 서비스
